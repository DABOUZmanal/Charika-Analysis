📊 Company Analysis
A simple Python project for analyzing and visualizing company sales, costs, and income over a period of 10 days.
🛠️ Technologies
Python
NumPy
Pandas
Matplotlib
📌 Project Description
This project generates a sample dataset containing:
Daily sales
Daily costs
Daily income
Income is calculated using:
Income = Sales - Cost
The data is then stored in a Pandas DataFrame and visualized using Matplotlib.
📈 Visualization
The chart displays three lines:
🔵 Sales
🔴 Cost
🟢 Income
🚀 How to Run
Clone the repository:
git clone https://github.com/YOUR-USERNAME/company-analysis.git
Go to the project folder:
cd company-analysis
Install the required libraries:
pip install -r requirements.txt
Run the program:
python company_analysis.py
