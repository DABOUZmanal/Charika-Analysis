# 📊 Company Analysis with Python

A simple data analysis and visualization project using **Python**, **NumPy**, **Pandas**, and **Matplotlib**.

## 📌 Project Overview

This project simulates a company's daily **sales**, **costs**, and **income** over a period of 10 days.

The data is generated randomly and organized into a Pandas DataFrame for analysis and visualization.

## 🛠️ Technologies Used

- 🐍 Python
- 🔢 NumPy
- 🐼 Pandas
- 📊 Matplotlib

## 📈 Data Visualization

The project creates a line chart to compare:

- 🔵 **Sales**
- 🔴 **Cost**
- 🟢 **Income**

The chart includes markers, different line styles, labels, a legend, and a grid.

## 🚀 Installation
